# Portfólio — Wagner Santos

Site pessoal criado para apresentar minha trajetória, habilidades e projetos na área de Tecnologia da Informação.

## Sobre

Sou estudante técnico em Informática, com interesse em desenvolvimento web, suporte técnico, análise de dados e soluções digitais. Este portfólio reúne projetos desenvolvidos durante minha formação e estudos.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Recursos do site

- Layout responsivo para computador e celular;
- Seções de apresentação, habilidades, projetos e contato;
- Cards de projetos gerados dinamicamente com JavaScript;
- Modal com informações e galeria de cada projeto;
- Menu de navegação para dispositivos móveis;
- Animações de entrada durante a navegação.
